agentflake

AI agents,
versioned like code.

Today your AI agent has a shell, your repo and your login. What stops it? A prompt that says "please don't", and a settings file anyone can change.

July 2025: an AI coding agent deleted a company's production database during a code freeze. (Replit / SaaStr)

For platform teams rolling AI agents out to every developer.

The idea

One file defines the agent. Git versions it.

# profiles/reviewer.nix (abridged) name = "reviewer"; version = "1.1.0"; packages = [ "ripgrep" "git" "shellcheck" ]; tools = [ "Read" "Grep" "Glob" "Bash" "Skill" "Agent" ]; filesystem.workspace = "read-only"; network.tools = "deny"; # web tools off skills = [ "acme-code-review" ]; behaviour.standards = [ "review" ];

Locked by the OS: the reviewer's repo, the home folder, its own rules

Company skills & standards included

Versioned by git: every release is a tag you can diff

agentctl diff v1.0.0 → v1.1.0 +shellcheck + security findings must cite a CWE id
Live → swap the agent, then tell it to break the rules
